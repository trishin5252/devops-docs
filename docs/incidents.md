# Журнал типовых инцидентов

| Инцидент | Признак | Источник диагностики |
|---|---|---|
| Неиспользуемая переменная | Красная проверка `pylint` в PR | Журнал шага Static analysis |
| Недостаточные права публикации | `build` успешен, `deploy` не получает OIDC-токен | Журнал `deploy-pages` и блок `permissions` |
| Битая ссылка | `mkdocs build --strict` завершается ошибкой | Журнал Build documentation |
| Старая версия после деплоя | Зелёный workflow, прежняя страница | URL окружения, публикация, кэш браузера |

## Правило разбора

Укажите симптом, затронутый компонент, доказательство из журнала, причину, исправление и проверку восстановления.
